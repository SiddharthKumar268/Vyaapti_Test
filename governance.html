5 Permanent Governance Rules (REGRESSION_PREVENTION.md)

Rule 1: @pytest.mark.compliance Blockers

Any test tagged with compliance must never be skipped or marked `xfail`. A single failure immediately halts the deployment pipeline.

Rule 2: Runtime Unit-Conversion Sanity Checks

Time conversion helpers assert `hours < 8760` (1 year). Catches `/60` vs `/3600` unit conversion bugs immediately at execution time.

Rule 3: Static Pre-Commit Regex Linter

Pre-commit hook scans for raw numeric literals (e.g. `49_50_000`) in comparison logic, enforcing centralized threshold constants.

Rule 4: Mandatory CODEOWNERS Approvals

All PRs touching `chain_scoring.py` require mandatory two-person sign-off: `@compliance-team` and `@lead-architect`.

Rule 5: Automated PR Triage Commenter

CI pipeline runs Bob 2.0 triage on any test failures and automatically posts the clustered root-cause matrix as a PR comment.
